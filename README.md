# Projeto Final - Desenvolvimento de Interfaces
Copa Libertadores da América - Histórico Conmebol Libertadores da América (v 2.0)

Divisão do projeto em etapas:
- index.html (estrutura da página principal)
- login.html (estrutura da página de login)
- style.css + Bootstrap (atributos e opções visuais) 
- script.js + Bootstrap (funções e abas interativas)
- Pasta de imagens usadas
	
O projeto possui:
- Conteúdo resumo completo da história da Conmebol Libertadores, da criação aos dias de hoje, dividida em cartões informativos.
- Carrossel de imagens interativo mostrando alguns dos títulos conquistados na atualidade.
- Uma aba de navegação no cabeçalho
- Lista de Campeões em formato de tabela responsiva
- Opções de acessibilidade: Modo claro/ Modo escuro; Botão para aumentar e diminuir a letra
- Página de login do usuário


Tecnologias utilizadas:
- HTML
- CSS
- JavaScript
- Bootstrap 5 (framework)
